# Phoenix Wire identity

Selected concept: **1 — luminous wire**. Original PhoenixMail phoenix/envelope identity,
orange/yellow/red flames, silver-white Phoenix lettering, warm Wire lettering; a thin
wire extends from the tail beneath the name. The supplied WebP derives from the logo
concept selected by the owner in this conversation. It is a raster concept, not yet a
production vector master; final small-size and contrast refinements remain.

Footer on web and future desktop: **Powered by Phoenix Mail** with a link to PhoenixMail.
The current link is https://phoenixmail.ca; confirm the desired public destination before release.

No existing PhoenixMail source assets or license were overwritten. This initial repository
uses newly written code and the selected concept, not a copy of the private mail client.
Review brand/trademark usage and third-party licenses before public release; the MIT
software license is not a claim to exclusive trademark rights.
